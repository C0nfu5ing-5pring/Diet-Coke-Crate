# Diet Coke Crate
It's a diet coke crate!

## Features

- Weight around 174 grams
- Can fit 4 300ml/330ml diet coke cans

## Design & Specifications

| Property | Value |
|---|---|
| Designed using | Onshape |
| Printer | Bambu Lab A1 Mini |
| Material | PLA |
| Infill | 15% |
| Layer Height | 0.2 mm |
| Supports | Required |
| Model Dimensions | 150 × 150 × 80 mm |
| Estimated Print Time | 7 hours 16 minutes |
| Filament Usage | 187 g  (with supports)|
